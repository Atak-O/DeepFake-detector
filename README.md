## 🎯 What Does This Project Do?
With the rapid rise of AI-generated imagery, it's getting harder to trust our own eyes. This project uses a custom-trained **Deep Neural Network** (built via Google Teachable Machine) to analyze images and classify them as either **Real** or **Deepfake**. 

Whether you are a researcher, a curious developer, or just someone who wants to verify a suspicious image, this script provides a quick confidence score on the authenticity of a picture directly from your browser.

## ✨ Key Features
* **Lightning Fast:** Analyzes and predicts image authenticity in seconds.
* **Google Colab Ready:** No heavy local GPU installation required; runs directly in the cloud.
* **Interactive UI:** Uses Colab's native file uploader for a seamless testing experience.
* **Confidence Metrics:** Doesn't just give a binary yes/no—it outputs a percentage score showing exactly *how sure* the AI is.
